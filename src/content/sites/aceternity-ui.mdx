# Aceternity UI

Aceternity UI is a collection of re-usable components that you can copy and paste into your apps.
It primarily uses Tailwind CSS and Framer Motion for animations.

## Key Features

- **Copy & Paste**: No npm install needed for most components.
- **Customizable**: Built with Tailwind CSS for easy customization.
- **Modern Design**: Focuses on cutting-edge, trendy aesthetics.
